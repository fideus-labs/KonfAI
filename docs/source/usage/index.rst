How-to guides
=============

Choose a path by the outcome you need. Running the
train → predict → evaluate workflows is covered by the
:doc:`configuration reference <../config_guide/index>`: each of its pages
starts with the commands that run its workflow.

Start here
----------

Read :doc:`adopting-konfai` if you already use PyTorch, MONAI, nnU-Net, or
Lightning. Read :doc:`making-data` when what you need is a dataset rather than a model.
Read :doc:`python-workflows` when a script or notebook fits better than the CLI. Read :doc:`large-images` when regional I/O and bounded host
memory matter. :doc:`custom-models` covers extension contracts and
:doc:`docker` covers a containerized runtime. Apps, agent automation and the
Studio chat UI have their own section in the main navigation: :doc:`apps`,
:doc:`mcp` and :doc:`studio`.
