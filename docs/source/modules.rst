Full module reference
=====================

This section documents the modules that make up KonfAI. It is intentionally broader
than the curated API pages and therefore includes lower-level helpers used by
extension authors. The stubs are **hand-maintained**, not generated, so the coverage
is partial: `konfai.data`, `konfai.metric` and `konfai.network` are complete, while
`konfai.models.**` and several `konfai.utils` helpers (`errors`, `runtime`,
`model_builder`, `ome_zarr`, `dicom`, `pretrained`, `vram`, `live_control`) and
`konfai.export` have no page yet. Read them from the source until they do.
