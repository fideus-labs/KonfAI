Studio

A chat web UI over the MCP server.

What it is

KonfAI Studio is a chat web interface over the MCP server: point it at a dataset, describe the task, and the assistant inspects, designs the config, validates it, trains, predicts, evaluates, compares, and opens the volumes in the viewer; a session is one isolated experiment workspace, and every run is frozen with its command, its environment and its config. Three ways in: use a published app as it is, fine-tune it, or train from scratch.

Install and open

python -m pip install konfai-studio
konfai-studio                           # -> http://127.0.0.1:8730
BrainWhat you needSetting
