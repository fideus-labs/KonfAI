Agents and MCP

What the MCP server lets an agent do.

What the server lets an agent do

KonfAI MCP exposes KonfAI to an MCP client (Claude Code, Codex, Studio) as fifty tools, one per object: inspect a dataset, design and write a config, check it without launching anything (up to one real forward and backward pass), launch and follow jobs, compare runs, use a published app, fine-tune it, package a session as an app, inspect a result with Scout, read a benchmark's catalogue. Every run is a job; most answers name the valid next calls.

pip install "konfai[imaging]" konfai-apps konfai-mcp
konfai-mcp            # stdio transport by default
[mcp_servers.konfai]
command = "/path/to/venv/bin/konfai-mcp"
tool_timeout_sec = 3600

[mcp_servers.konfai.env]
KONFAI_MCP_WORKSPACES_ROOT = "/path/to/workspaces"
