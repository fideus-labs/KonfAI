Edge

KonfAI apps in a browser tab, no server.

What it is

KonfAI Edge is the Rust runtime that runs KonfAI apps in a browser tab, with no server: the apps of the Hugging Face catalogue, their inference, evaluation and uncertainty, beside one viewer, on the machine that opens the page. Its demo site is being added to the fideye repository (pull request 847, konfai-edge/web/).

What the demo holds

  • Web Components: <konfai-app> (an app's inference, evaluation and uncertainty beside one viewer) and its parts <konfai-inference>, <konfai-evaluation>, <konfai-uncertainty>, <konfai-viewer>, plus <konfai-workflow> for a TRANSFORM or EVALUATION program over a dataset folder. Another page embeds them with one import.
  • The site that consumes them: a catalogue, one page per app, the workflows; a static server with an optional mirror of the bundles' web/ folders.
  • The engines the site serves itself, built to WebAssembly: the registration glue (FireANTs and ConvexAdam with the IMPACT loss), ITK-wasm's elastix with the IMPACT metric, and the 3D view.
  • Streamed processing of large images and remote data sources; a job tray with progress, previews, cancellation and downloadable results.

Where it will live

This site is the home of that demo: once the pull request lands, the demo moves under edge/ here and this page links to it, app by app. Until then, the apps run through konfai-apps on your machine, or through Studio.
