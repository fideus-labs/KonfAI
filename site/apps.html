KonfAI Apps

A stable KonfAI workflow, packaged with its weights and configuration as an app. The same app runs from a local folder, a Hugging Face repository or an HTTP server; from its own one-line CLI, from the generic konfai-apps runtime, from 3D Slicer, or as a tool of the MCP server. Consuming a published workflow does not require authoring YAML; the complete configuration stays available when you need to inspect, evaluate, fine-tune or automate it.

pip install impact_synth_konfai
impact-synth-konfai synthesize MR -i input_mr.nii.gz -o output/
# the same packaged workflow through the generic app runtime
konfai-apps infer VBoussot/ImpactSynth:MR -i input_mr.nii.gz -o output/

The runtime: konfai-apps

konfai-apps is the standalone package for packaged workflows: local inference and evaluation, reusable app packaging, remote execution through a FastAPI server, integration in external tools such as 3D Slicer. It ships three interfaces: the konfai-apps command for local or remote execution, konfai-apps-server for hosting apps behind an HTTP API, and the Python API under konfai_apps. It depends on konfai and is versioned and tested as a separate runtime surface.

python -m pip install konfai-apps              # run apps, locally or against a server
python -m pip install "konfai-apps[server]"     # host apps behind an HTTP API

In 3D Slicer: SlicerKonfAI runs segmentation, synthesis, evaluation and uncertainty apps; SlicerImpactReg runs the IMPACT-Reg presets and shows the registration results.

Guides: Ship an App, the CLI reference, the HTTP server API. Source: konfai-apps/ and apps/.
